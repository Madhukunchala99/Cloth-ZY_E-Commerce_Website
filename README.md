# Clothzy – E-Commerce Website

Clothzy is a full-stack e-commerce website developed using the MERN stack. It provides an online shopping experience where users can explore clothing products, view product details, and shop through a user-friendly interface.

## Features

* User-friendly and responsive interface
* Browse and explore clothing products
* View product details
* Shopping cart functionality
* User authentication and account management
* Product and order management

*Note: The features listed above should match the functionality implemented in your project.*

## Getting Started

### Prerequisites

Make sure you have the following installed:

* Node.js
* npm
* MongoDB, if the application uses a local MongoDB database

### Installation

1. Clone the repository:

   ```bash
   git clone https://github.com/Madhukunchala99/Cloth-ZY_E-Commerce_Website.git
   ```

2. Navigate to the project directory:

   ```bash
   cd Cloth-ZY_E-Commerce_Website
   ```

3. Install dependencies:

   ```bash
   npm install
   ```

4. Start the development server:

   ```bash
   npm run dev
   ```

5. Open the local URL displayed in your terminal, usually `http://localhost:5173`.
